# ClipAI 3.7.21

## Changes

- Right Alt opens the Inline Dictation pill with clearer listening, processing,
  refinement and recovery feedback. The compact circular presentation keeps
  notifications above the pill without moving its controls.
- Input recovery preserves frozen clipboard choices and requires a fresh
  confirmation key press. Selection worker cleanup and interruption handling
  prevent stale operations from affecting newer input.
- Popup, Entry Panel and Inline Dictation now start at the bottom center of the
  starting pointer monitor. Existing dragged windows keep their position. The
  simplified English Tray menu removes position controls and preserves other
  preferences when migrating saved settings.
- Entry Panel improves Recent cards and adds a fixed root slot 8, "Ask about
  this", reusing the prepared source without contacting a provider until the
  first question is submitted.
- Command generation, risk review and coaching are separate Actions.
  Ctrl+Alt+B generates commands; Ctrl+Alt+C retains risk review; coaching is
  available through Tools More/search. Both official language packs include
  task-specific guidance and feedback.
- Fix stale punctuation key state that could disable later Alt shortcuts.

## Installation and upgrade

Windows 11 x64. Windows Setup is **unsigned**; Windows may show an unknown
publisher or SmartScreen prompt. Managed bundles retain production Ed25519
signatures. Existing official installations with stable launcher 3.7.18 can use
About Update. App updates retain the installed launcher and user data.

## Validation and disclosed acceptance gaps

Local verification passed 2,493 unit tests, including the architecture suite;
the architecture suite also passed separately with 65 tests. Both official
language packs passed validation. Official packaged-candidate verification
results are recorded with the final release assets. Automated Windows runner
installation checks do not establish independent device or user acceptance.

Independent clean Windows 11 standard-user acceptance, final-device failure
recovery, reboot, cross-logon, browser trust and first-time-user observations
remain pending unless separately recorded for this exact candidate. Command
output quality and learning effectiveness also require human review. Pending
checks are never represented as passed; the default readiness gate is unchanged.
The maintainer explicitly accepts these disclosed gaps for 3.7.21 publication
after automatic verification passes. Final Setup and Bundle identities and the
version-specific decision are recorded in the published acceptance.json.
