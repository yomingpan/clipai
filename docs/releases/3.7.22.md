# ClipAI 3.7.22

## Changes

- Result Popups use a clearer reading hierarchy, higher contrast for source
  text, and more space between wrapped lines. Idle actions use quieter styling.
- Traditional Chinese vocabulary explanations emphasize the core definition
  before the example and optional usage details.
- Keyboard input remains available when voice input is disabled.

## Installation and upgrade

Windows 11 x64. Existing official installations with stable launcher 3.7.18
can use About Update. App updates retain the installed launcher and user data.
Managed bundles use production Ed25519 signatures. Windows Setup may show an
unknown publisher or SmartScreen prompt when unsigned.

## Validation

Automated verification and final asset identities are recorded with the release
assets. Independent clean Windows 11 standard-user, reboot and cross-logon,
failure recovery, browser trust, and first-user observations require separate
evidence for the final candidate.
