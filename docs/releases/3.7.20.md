# ClipAI 3.7.20

This release adds an experimental window position preference and improves
selection capture while keyboard modifiers are held.

## Changes

- Popup windows and Inline Dictation independently offer Follow Cursor and
  Bottom Center. Both default to Bottom Center. The Tray's new Popup Window
  Position menu sits directly below Inline Dictation. Entry Panel shares the
  Popup shell and its position preference.
- Position changes are saved and apply to the next new window or Inline
  interaction. Existing windows keep their current position. Existing saved
  Inline position choices are preserved; Minimal Input and Full Choice use the
  same Inline position preference.
- Read-only selection detection runs before waiting for keyboard modifiers to
  be released. Modifier release remains required only for a positively supported
  Copy fallback. Unknown selection evidence does not become empty selection or
  silently use stale clipboard content.

## Installation and upgrade

Windows 11 x64. The Windows Setup remains **unsigned**; Windows may show an
unknown publisher or SmartScreen prompt. Managed bundles retain production
Ed25519 signatures. Existing official installations with the 3.7.18 stable
launcher can use About Update. App updates retain the installed launcher and
user data. ClipAI Candidate uses a separate installation and trust identity.

## Validation

Local verification passed 2,160 unit tests, including the architecture suite;
the architecture suite also passed separately with 62 tests. Real Windows UI
smokes verified both Popup positions, both Inline positions, and Entry Panel
startup/closure. Layout tests cover DPI scaling and negative monitor origins.

Official source CI, compiled installer and exact asset validation will be
recorded against this version's final candidate. Independent clean Windows 11
standard-user, final-device failure recovery, reboot, cross-logon, browser trust
and first-time-user observations remain pending until supplied. Previous
version-specific acceptance does not establish those gates for this release.
