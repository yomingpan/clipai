# ClipAI 3.7.19

This maintenance release simplifies managed update and Windows installation
verification while preserving existing signing, rollback and data ownership.

## Changes

- Release build and asset checks share the same complete Bundle admission as
  installation and automatic update: signature, schema, version and exact file
  inventory. Release provenance must include every admitted wheel.
- Windows shortcuts are processed in bounded phase batches. Installation and
  removal need four worker launches instead of nine for a three-shortcut cycle,
  with fresh ownership checks before payload and native integration removal.
- Runtime packaging extracts directly into its final filtered layout, avoiding
  an intermediate runtime copy. Installation verification inventories installed
  distributions once, and the update verification harness runs its unit suite once.

## Installation and upgrade

Windows 11 x64. The Windows Setup is **unsigned**; Windows may show an unknown
publisher or SmartScreen prompt. Managed bundles retain Ed25519 signatures.

Existing official installations with the 3.7.18 stable launcher can use About
Update. App updates do not replace the stable launcher or Setup engine; the
shortcut batching improvement applies to the new 3.7.19 Setup engine. Older
launcher installations require the retained-data Setup maintenance procedure.
ClipAI Candidate uses separate roots and trust identity; its settings and keys
are not automatically transferred to the official installation.

## Validation

Local refactor verification passed 2055 unit/architecture tests and five real
integration tests, including Windows Unicode shortcut ownership and managed
bundle installation/update/recovery. Local shortcut-phase measurements showed
5.87 to 3.06 seconds median over five samples per mode. This does not measure
complete installer or CI release duration.

Final source CI, compiled Setup and exact asset results are recorded with the
release candidate. Independent device/user acceptance statuses remain explicit
in acceptance.json; no prior candidate evidence is relabeled for this release.
