# ClipAI Popup 閱讀性研究

ClipAI 的結果視窗同時支援短暫查閱、較長的閱讀，以及使用者主動選擇的學習。評估時應分別看能否快速找到答案、是否正確理解，以及常用操作能否順利完成。學習任務可另外量測回想或造句。右上角的 Human Space 讓有需要的人查看 AI 與人的分工。 [產品哲學](../Product_philosophy.md)

## 本次調整的依據與限制

| 調整 | 可確認的變化與研究限制 |
| --- | --- |
| 提升正文與來源的明度對比 | 依 W3C 相對亮度公式，以 `#2B2B2B` 當背景計算，正文從 10.62:1 提升為 12.21:1，來源從 2.86:1 提升為 7.20:1。來源改善最明確，從低於 WCAG 一般文字 4.5:1 的參考值提升到超過門檻。計算反映指定色值，閱讀速度、疲勞和暖白色相的獨立效果尚待實測。 [Popup 樣式](../../ClipAI/ui/base_dialog.py) · [W3C 文字對比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [WCAG2ICT](https://www.w3.org/TR/wcag2ict-22/) |
| 以字級、字重、留白和中性色區隔標題 | 文字理解實驗顯示標題訊號的效益會受其與正文的內容關聯和距離影響，對提示主題較有依據，對所有細節的回想效果有差異。短詞義可以直接呈現，長摘要仍需要有資訊量的標題。實驗未比較此 Popup 的藍色和暖白色。 [標題訊號實驗](https://doi.org/10.1016/j.cedpsych.2007.11.001) |
| 加大自動換行行距 | Tk 的 `spacing2=3` 調整同一邏輯行自動折行後的空間，段落與標題間距另由樣式處理。Chaparro 等人的英文螢幕長文實驗中，兩種行距影響偏好，未觀察到閱讀表現差異。有較大頁邊距的受試者讀得較慢但理解較佳。材料約 800 個英文單字，無法直接推定小型繁中 Popup 的最適行距。W3C 的 1.5 倍是容許使用者調整的測試條件，WCAG2ICT 說明其適用於使用標記語言且容許調整文字間距的軟體。 [Tk Text 文件](https://www.tcl-lang.com/man/tcl8.6/TkCmd/text.htm) · [留白與行距實驗](https://citeseerx.ist.psu.edu/document?doi=9aee1890770faca2cdf36c87478531553ff0b18d&repid=rep1&type=pdf) · [WCAG2ICT 文字間距](https://www.w3.org/TR/wcag2ict-22/#text-spacing) |
| 弱化工具列，詞彙首段突出核心詞義 | 閒置按鈕透明化，操作中的圖示與底色繼續表達真實狀態。英文詞仍在首行，粗體中文詞義在接下來的解說段。這些是基於掃讀目標的產品假設，還需要確認找答案變快時，點擊複製與朗讀也能維持清楚。 [Popup 操作樣式](../../ClipAI/ui/base_dialog.py) · [英文詞彙解析](../../config/language_packs/zh-TW/actions.yaml) |

## 下輪最值得驗證的方向

1. **先檢查剩餘文字及操作狀態的對比。** 目前名義色值中，模型標籤和分析中灰字對深灰背景分別約 2.71:1、2.86:1。按鈕暖白成功勾對亮綠底約 2.47:1，如以圖示辨認成功，可參考非文字對比 3:1。用實機逐一確認預設、鍵盤焦點、待處理、失敗與完成的相鄰色，並檢查圖示及提示能否辨認狀態。 [W3C 文字對比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [W3C 非文字對比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)
2. **測短結果與長結果各自適合的文字密度。** 可先比較目前正文 14 與 16 邏輯像素，再固定字級比較折行間距 3 與 5；這些數字是測試條件。用繁中、英文、混排和密筆畫字，記錄第一屏可見字數、正確理解和捲動。中文眼動實驗發現詞界插空格與自然排法的整句時間相近，逐字或錯誤切分反而造成干擾。另一實驗中，字距加寬伴隨較短但較多的注視。這兩者研究的是水平字距與詞界，對增加垂直行距沒有提供直接證據。 [中文詞界眼動實驗](https://pmc.ncbi.nlm.nih.gov/articles/PMC2662925/) · [字距與年齡眼動實驗](https://jps.ecnu.edu.cn/CN/Y2020/V43/I1/68)
3. **單獨比較首屏的內容順序。** 單字先試「詞義與一個例句」，其餘用法接在後面。翻譯保持譯文優先，長摘要留有意義的段落標題。把練習、回想或造句放在使用者選擇的學習情境，避免拖慢臨時查閱。產品文件的「5±2」可用來提醒取捨，工作記憶容量研究的單位是特定任務中的資訊組塊，並未為 Popup 的段落數量建立固定上限。 [工作記憶條件與組塊](https://doi.org/10.1017/S0140525X01003922) · [產品哲學](../Product_philosophy.md)
4. **再評估是否有淺色閱讀選項的需求。** Piepenbrock 等人發現 8–14 pt 校對時，深字淺底表現較好，字愈小差距愈大。可以在不同環境亮度比較兩種極性，分別記錄正確率、舒適度及使用者偏好。研究場景是校對，對目前深色 Popup 的短讀效果、疲勞或混排沒有直接結論。 [顯示極性校對實驗](https://doi.org/10.1177/0018720813515509)

Wang 等人的中文多行閱讀實驗中，欄數與對齊方式改變了從行尾跳到下一行的眼球落點與修正動作，整體閱讀時間與理解沒有顯著差異。這支持在長摘要實測欄寬和換行的取捨，也說明眼動變化本身不足以判定閱讀體驗改善。 [中文多行閱讀眼動實驗](https://doi.org/10.1186/s41235-024-00559-5)

Roediger 和 Karpicke 的英文短文實驗中，主動回想比重讀更有利於兩天與一週後的保留。可在現有練習 Recipe 驗證同一原則，例如先試著回想詞義再揭曉。短文的效果需要用 ClipAI 的詞彙任務另行確認。 [回想練習實驗](https://doi.org/10.1111/j.1467-9280.2006.01693.x)

## 驗證方式

用凍結的結果與相同的視窗尺寸比較排版，交錯版本與材料順序，避免先閱讀同一答案帶來的練習效應。分開量測找到第一個正確答案的時間、理解正確率、第一次捲動、操作誤點與完成時間，再問閱讀舒適度。用相同的按鈕任務比較透明底和原樣式，納入鍵盤使用者以及 100%、125%、150% Windows 顯示縮放。正文、間距、答案順序和按鈕一次只改一組。詞彙練習另外做延遲回想，與快速查閱用不同判準。測試材料使用固定範例，回饋用於驗證呈現效果。
