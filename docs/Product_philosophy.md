# CEO哲學: 
**AI是輔助人類駕駛，幫助人類減少平常任務需要的摩擦力，主動選擇需要增加的摩擦力ex.英文學習、domain學習。**


# 功能: 
- 使用剪貼簿與快捷鍵，讓AI輔助自己理解，理解內容、學習英文、語言翻譯、潤飾文字、縮短內容、洞察好問題...。


# Human Space

- 每個可回饋的 Recipe 都要說清楚兩件事：AI 幫你做什麼，以及 AI 不替你做什麼。第二項必須具體照亮仍由人判斷的方向、立場、價值取捨與最後選擇。
- 每個會產生 AI Popup 結果的 Shortcut 都應具備這份契約；短按與長按若是不同任務，必須使用各自適合的 Human Space 與回饋原因。
- AI 優先承接操作與 context 轉換；立場、關係、品味、因果與最後選擇仍由人掌握。
- `Esc` 是使用者收回控制權的全域煞車：有取得焦點的 ClipAI utility panel 時先關閉該 panel；否則取消仍可能改變可見結果的 ClipAI 工作，並阻止已排程的後續輸出。
- 回饋是改善 Recipe 的證據，不是讓系統默默改寫 Prompt 的授權。只有使用者明確同意，才保存包含原文與結果的案例。
- 這份界線由右上角 `ⓘ` 隨取隨看，不預設自動跳出或占用結果空間。若結果不符合預期，使用者可按回饋按鈕或 `Ctrl+R` 回饋。


# Senario example
- 複製appetizer這個字在剪貼簿，使用快捷鍵(ex. ctrl+alt+8短按)，跑出一個小小window視窗，簡單清晰的排版，ex. summary/meaning/context/example/synonyms。然後滑鼠隨時點開，視窗就消失。


# 品味:
內容需要減少使用者的認知負荷(關鍵認知點不要超過5+-2個，不然大腦會混亂)，用常用通用的框架來表達。
