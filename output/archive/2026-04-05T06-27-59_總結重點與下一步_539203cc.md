Key Changes
1. Header button presentation
Replace text buttons for Speak, Copy, and Archive with icon-only buttons.

2. Fix Speak state so red Stop persists correctly
Investigate the current TTS state flow between popup_presenter.py, tts_service.py, and tts.py.
Current likely cause:
popup sets the button to Stop immediately from toggle_async()
then an early non-start TTS event or rapid stop/start edge resets the UI back to normal too aggressively
Make popup state transitions phase-aware instead of treating every non-start event as “not speaking”.
Keep the red Stop state active until an actual terminal TTS phase is reached: end, stop, or error.
Prevent transient startup behavior from immediately reverting the button when playback has actually begun.
Ensure repeated presses still behave as true toggle:
idle -> start speaking -> red Stop
speaking -> stop playback -> normal Speak
3. Follow-up shortcut change
Replace Ctrl+M binding with Ctrl+/ in the popup-local shortcut registration.
Keep the rest of the Follow-up behavior unchanged:
hidden by default
toggles open/closed
focuses input when opened
Preserve coexistence with the secondary action row.
4. Popup proportional downscaling
Reduce the computed popup width and height in the window sizing logic.
Keep the resize proportional rather than only shrinking one dimension.
Scale down related layout constants only where needed so the window still feels balanced:

Do not redesign the layout; keep the same structure and just make it visually tighter.
